## 怎么看这张表

1. 剪枝是「纯赚」：节点数大幅下降，而同一深度的着法与分数一位不差 → 
论文里可以写成 *pruning reduces the search tree without changing the decision*。
2. 省下的比例越大，说明走法越好找、树越窄；深度越深、局面越封闭，省得越多。
3. 这张表只回答「剪枝省多少」，不回答「哪档更强」——强度是 G1/G2 的活。
